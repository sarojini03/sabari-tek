# Sabari Tek Professional Website

A responsive, single-page business website for Sabari Tek CCTV & Security Solutions.

## Files

- `index.html` — website content and structure
- `styles.css` — responsive styling and visual design
- `script.js` — mobile menu, FAQ accordion, scroll effects and WhatsApp form
- `assets/favicon.svg` — browser icon

## Run locally

Double-click `index.html`, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

Upload all files and the `assets` folder to the same public web directory on your hosting provider.

## Update business details

Search the project for `7845702829` to update the phone/WhatsApp number.
Edit the location, services and customer-review text directly in `index.html`.

## Contact form behavior

The form validates the enquiry and opens WhatsApp with a pre-filled message. It does not require a backend and does not store visitor data.
